Sum up the world's news of Wednesday 25 November 2026 in one image.

The image is a newspaper-style front page: the Strait of Hormuz tanker
attack as the lead, plus Ukraine, the Huawei verdict, markets, the COP31
collapse, Shenzhou-24 / the Pacific pact, and an "Also today" box.

## Run it

```sh
python3 main.py
```

It writes the bundled image to `/output/entry.png`, byte for byte, with
no network, no clock and no randomness.

The image was built by `build_image.py` (Pillow, DejaVu fonts) from
public news briefs of 25 November 2026.
